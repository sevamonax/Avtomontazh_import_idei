# Автомонтаж вертикальных роликов

Конвейер, который берёт сырую съёмку «говорящая голова» и сам собирает из неё
готовый вертикальный ролик 1080×1920: режет паузы и брошенные заходы,
кадрирует под 9:16, рисует субтитры и графику, сводит звук и проверяет
результат шестнадцатью проверками, прежде чем отдать его вам.

Человек в этом участвует дважды: выбирает куски из таблицы кандидатов и
смотрит готовый ролик на приёмке. Всё остальное делает механизм.

> ### 👉 Не программист? Вам сюда: **[МАНУАЛ.md](МАНУАЛ.md)**
>
> Запускать скрипты руками не нужно. Вы ставите себе ИИ-помощника (Claude Code
> или Codex), открываете его в этой папке и разговариваете с ним обычными
> словами: «собери ролик из папки со съёмкой». Он прочитает `CLAUDE.md`, поймёт
> устройство конвейера и всё запустит сам — включая две остановки, на которых
> решение за вами.
>
> Этот README — про то, как конвейер устроен. `МАНУАЛ.md` — про то, как им
> пользоваться.

**Это не сервис и не приложение.** Это набор скриптов, который вы запускаете у
себя, правите под себя и разбираете на части, если нужно. Он написан под один
конкретный способ съёмки — человек говорит в камеру, дублей много, половина
заходов брошена, — и именно на нём работает хорошо.

## Что он делает на самом деле

| Шаг | Что происходит | Сколько ждать* |
|---|---|---|
| `rech.py` | расшифровка по всплескам речи + пословный тайминг | ~13 мин |
| `dubli.py` | мусор, огрызки, группы пересъёмок → чистая речь | секунды |
| `otbor.py` | куски-кандидаты со счётом — **остановка 1: таблица на приёмку** | секунды |
| `rez.py` | монтажный лист: что откуда берём | секунды |
| `kadr.py` | замер лица → вертикальное окно и крупности | ~2 мин |
| `titry.py` | субтитры на таймлайне + акценты | секунды |
| `sborka.py` | рендер вертикали + громкость — **остановка 2: прочитать текст** | ~6 мин |
| `proverki.py` | гейт: шестнадцать проверок, не рендерить брак | секунды |
| `render_reel.mjs` | экранный слой с прозрачностью | ~10 мин |
| `proverki.py` | гейт ещё раз: теперь меряется нарисованный слой | ~1 мин |
| `nalozhit.py` | композит → готовый ролик | ~1 мин |
| `kadry.py` | лист контрольных кадров к приёмке | ~1 мин |
| `finaly.py` | **единственная дверь в папку финалов** | секунды |

\* замер на четырёх файлах 4K, 6:50 сырья, обычный ноутбук без видеокарты.
Расшифровка кэшируется, куски сборки кэшируются по содержимому — правка
одного куска не пересобирает остальные.

## Как это запускается

```bash
python rech.py     --проект "МОЙ РОЛИК"
python dubli.py    --проект "МОЙ РОЛИК"
python otbor.py    --проект "МОЙ РОЛИК"       # ← ОСТАНОВКА 1: таблица кандидатов
python rez.py      --проект "МОЙ РОЛИК" --кандидат 1
python kadr.py     --проект "МОЙ РОЛИК"
python titry.py    --проект "МОЙ РОЛИК"
python sborka.py   --проект "МОЙ РОЛИК"       # ← ОСТАНОВКА 2: прочитать текст сборки
python proverki.py --проект "МОЙ РОЛИК"
node ../слой/render_reel.mjs "../проекты/МОЙ РОЛИК/titry.json" "../проекты/МОЙ РОЛИК/выход/слой.mov"
python proverki.py --проект "МОЙ РОЛИК"
python nalozhit.py --проект "МОЙ РОЛИК"
python kadry.py    --проект "МОЙ РОЛИК"
python finaly.py   --проект "МОЙ РОЛИК" --серия "Моя серия"
```

Ролик снят целиком, без отбора кусков — шаг `otbor.py` пропускается, а границы
задаются вручную:

```bash
python rez.py --проект "МОЙ РОЛИК" --окна "01:2.1-9.2/целиком, 01:81-152, 02:19-301"
```

Отдельно, вне основного порядка, — **сверка спорного места** (§8 в `ЭКРАН.md`):

```bash
python okno.py --проект "МОЙ РОЛИК" --окно 105-114
```

## 🔑 Главное устройство: скрипты отдельно, ролик ключом

Скрипты лежат в `скрипты/` и **общие для всех роликов**. Конкретный ролик
приходит аргументом `--проект`. Новый ролик = новая папка в `проекты/` плюс
`proekt.json` внутри. **Кода при этом не трогают.**

Это не косметика. Если скрипты живут внутри папки ролика, то «механизм для
любого ролика» держится на том, что папку копируют целиком — вместе с
решениями по прошлому ролику, зашитыми в код. Через полгода таких копий пять,
и ни в одной не разобрать, где механизм, а где чужая правка.

От ролика к ролику меняется ровно одно: **`proekt.json`**.

## Две остановки — и почему их именно две

**Остановка 1 — таблица кандидатов, до всякого рендера.** `otbor.py` считает
куски и печатает их с баллами в `КАНДИДАТЫ.md`. Правка в таблице стоит минуту,
та же правка после рендера — час.

**Остановка 2 — прочитать текст собранного ролика, до слоя.** Обязательна.
Гейт сверяет результат с планом и не видит того, что потерялось **до** плана:
тихое слово, срезанное вместе с паузой, и повтор, который расшифровка вычистила
на всплесках. Разбор — `ЭКРАН.md` §8. Нашлось — правки и `sborka.py` ещё раз.

## Файлы проекта

Всё, что механизм насчитал, лежит рядом с `proekt.json` и читается глазами.

| Файл | Что внутри |
|---|---|
| `proekt.json` | **вход**: где сырьё, какие файлы, ручные правки |
| `rech.json` · `РЕЧЬ.md` | всплески речи с пословным таймингом |
| `chisto.json` · `ПЕРЕСЪЁМКИ.md` | чистая речь + все группы пересъёмок на приёмку |
| `kandidaty.json` · `КАНДИДАТЫ.md` | куски-кандидаты со счётом — остановка 1 |
| `edl.json` · `ЛИСТ.md` | монтажный лист + что вырезано и почему |
| `lico.json` · `crops.json` · `КРУПНОСТИ.md` | замер лица, окна, крупности |
| `titry.json` · `СЛОЙ.md` | субтитры на таймлайне и акценты |
| `ГЕЙТ.md` | отчёт проверок + честный список «остаётся глазам» |
| `ЛИСТ_КАДРОВ.md` + PNG | контрольные кадры: по кадру на кусок и на акцент |
| `выход/` | сборка и готовый ролик |
| `seg/`, `wav/` | кэш кусков и дорожек; чистятся после приёмки |

`слой.mov` весит 0,8–6 ГБ и удаляется сам после того, как композит проверен.
Нужен ещё на одну версию — `nalozhit.py --оставить-слой`.

## Границы честно

Чтобы вы не потратили вечер зря:

- **Русская речь.** Модель расшифровки многоязычная (язык меняется в
  настройках), но словари отбора, знаков и регулярные выражения написаны под
  русский. На другом языке отбор и знаки нужно переписывать.
- **Один человек в кадре.** Замер лица ищет одно лицо; диалог и два человека
  в кадре не поддержаны.
- **Говорящая голова.** Нет обработки b-roll, склеек по движению, музыки.
- **Инфографика пишется под каждый ролик.** Набор сцен пуст намеренно — это
  место для ваших сцен, а не забытая работа (`ЭКРАН.md` §6). Проверка В16,
  которая её требует, по умолчанию выключена.
- **Механизм не заменяет приёмку.** Список того, что он не ловит, печатается на
  каждом прогоне гейта и лежит в `ГЕЙТ.md`. Он обязан сокращаться, а не
  выглядеть пустым.
