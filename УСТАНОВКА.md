# УСТАНОВКА.md

Ставится в четыре шага. После каждого есть проверка — не пропускайте их: все
типовые поломки этого конвейера начинаются с «вроде поставил».

---

## 1. Python и библиотеки

Нужен **Python 3.8 или новее**.

```bash
python --version          # или python3 --version
```

Ставим зависимости — лучше в отдельное окружение, чтобы не смешивать с другими
проектами:

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

**Проверка:**

```bash
python -c "import numpy, cv2, faster_whisper; print('библиотеки на месте')"
```

> **Windows:** если в консоли вместо русского текста кракозябры, поставьте
> переменную окружения `PYTHONUTF8=1`. Скрипты пишут отчёты в UTF-8, и без
> этого Windows пытается читать их в своей кодировке.

## 2. ffmpeg и ffprobe

Без них не работает ничего: они и режут, и кодируют, и меряют.

| Система | Команда |
|---|---|
| Windows | `winget install Gyan.FFmpeg` (или скачать с ffmpeg.org и добавить в `PATH`) |
| macOS | `brew install ffmpeg` |
| Ubuntu/Debian | `sudo apt install ffmpeg` |

**Проверка:**

```bash
ffmpeg -version
ffprobe -version
```

Обе команды должны отвечать. `ffprobe` идёт в комплекте с ffmpeg, но в
некоторых сборках его забывают положить в `PATH` — а конвейер проверяет им
целость кэша и длину готового файла.

### Кодировщик видео

Конвейер сам выбирает самый быстрый доступный кодировщик и **говорит вслух**,
какой взял. Аппаратные кодировщики быстрее в разы, но есть не у всех:

| Кодировщик | Кому доступен |
|---|---|
| `h264_qsv` | встроенная графика Intel |
| `h264_nvenc` | видеокарта NVIDIA |
| `h264_videotoolbox` | Mac |
| `libx264` | **везде**, где есть ffmpeg — медленнее, но работает всегда |

Ничего настраивать не нужно: при значении `авто` (по умолчанию) берётся первый
доступный. Посмотреть, что у вас есть:

```bash
ffmpeg -encoders | grep h264      # Windows: ffmpeg -encoders | findstr h264
```

Принудительно задать — ключ `видео.кодировщик` в `настройки.json`.

## 3. Модель распознавания речи

Ставится вместе с `requirements.txt` (пакет `faster-whisper`), но **веса
модели скачиваются при первом запуске** — около 1,5 ГБ для `large-v3-turbo`.
Это разовая загрузка, дальше модель берётся из кэша.

Скачать заранее, чтобы первый настоящий прогон не ждал:

```bash
python -c "from faster_whisper import WhisperModel; WhisperModel('large-v3-turbo', device='cpu', compute_type='int8'); print('модель на месте')"
```

Мало места или слабая машина — поставьте в `настройки.json` модель поменьше
(`medium`, `small`). Качество расшифровки упадёт, и это скажется на отборе
кусков и на субтитрах: механизм работает с тем текстом, который ему дали.

Есть видеокарта NVIDIA — поставьте `"устройство": "cuda"`, станет в разы
быстрее.

## 4. Экранный слой (Node + Remotion)

Нужен, только если вы рисуете субтитры и графику. Резать паузы и собирать видео
конвейер умеет и без него.

```bash
cd слой
npm install
```

**Проверка:**

```bash
npx remotion studio src/index.ts
```

Откроется окно предпросмотра с композицией `Reel`. Первый запуск скачивает
браузер для рендера — это тоже разовая загрузка.

> Шрифты (Prata, Manrope, PT Mono) подтягиваются из Google Fonts автоматически,
> ставить их в систему не нужно.

## 5. Проверка на настоящем материале

Самое важное. Положите **один короткий файл** (30–90 секунд, говорящая голова)
в отдельную папку и заведите проект:

```bash
mkdir -p "проекты/ПРОБА"
cp проекты/_ШАБЛОН_proekt.json "проекты/ПРОБА/proekt.json"
```

Откройте `проекты/ПРОБА/proekt.json` и впишите путь к папке с этим файлом в
ключ `сырьё`. Дальше:

```bash
cd скрипты
python rech.py   --проект "ПРОБА"     # расшифровка — самый долгий шаг
python dubli.py  --проект "ПРОБА"
python otbor.py  --проект "ПРОБА"
```

Если в `проекты/ПРОБА/` появились `РЕЧЬ.md`, `ПЕРЕСЪЁМКИ.md` и `КАНДИДАТЫ.md` и
в них читаемый текст — установка в порядке, дальше можно собирать.

Отдельно стоит прогнать проверку проверок — она ничего не рендерит и отвечает
за секунды:

```bash
python proverki.py --проект "ПРОБА" --selftest
```

Каждая проверка должна «закричать» на подсаженном ей дефекте. Молчащая проверка
выглядит точно так же, как чистая сборка, — отличить их можно только так.

## Если что-то не работает

| Что видно | В чём дело |
|---|---|
| `ffmpeg не найден` | ffmpeg не в `PATH`. Перезапустите терминал после установки |
| `Unknown encoder 'h264_qsv'` | аппаратного кодировщика нет; поставьте `"кодировщик": "libx264"` |
| `нет папки сырья` | путь в `proekt.json` → `сырьё` не существует или указан с опечаткой |
| `в папке сырья нет видеофайлов` | ищутся `.mov`, `.mp4`, `.m4v`; переименуйте или добавьте расширение |
| расшифровка идёт часами | это нормально на CPU для длинного сырья; возьмите модель меньше или `cuda` |
| кракозябры в отчётах на Windows | `PYTHONUTF8=1` |
| `no space left` на рендере слоя | слою нужно 0,8–6 ГБ временно; освободите место |
