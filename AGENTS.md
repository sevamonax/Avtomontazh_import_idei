# AGENTS.md — контекст конвейера для ИИ-помощника

Правила для всех ИИ-помощников (Codex, Cursor, Copilot и прочих) лежат в
**[`CLAUDE.md`](CLAUDE.md)** — файл общий, он не только для Claude.

Прочитай его целиком до первого запуска. Там семь правил, без которых
конвейер ломается, порядок шагов и таблица «что делать с правками человека».

Дублировать правила сюда не нужно: разъехавшиеся копии одного правила — это
ровно та поломка, от которой конвейер защищается воротами.
