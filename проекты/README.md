# проекты/

Одна папка — один ролик. Внутри `proekt.json` (вход) и всё, что механизм
насчитал (выход).

Новый ролик заводится так:

```bash
mkdir "проекты/МОЙ РОЛИК"
cp "проекты/_ШАБЛОН_proekt.json" "проекты/МОЙ РОЛИК/proekt.json"
```

Дальше откройте `proekt.json` и впишите путь к папке с сырьём в ключ `сырьё`.
Разбор всех ключей — `НАСТРОЙКА.md`, часть 2.

**Кода при этом не трогают.** Скрипты общие и лежат в `скрипты/`, ролик
приходит аргументом `--проект "МОЙ РОЛИК"`.

---

Сами папки роликов лежат в `.gitignore`: в них уезжают гигабайты кэша и
готовые файлы. Если хотите версионировать свои `proekt.json` — добавьте их
принудительно:

```bash
git add -f "проекты/МОЙ РОЛИК/proekt.json"
```

Это разумно: `proekt.json` — единственный файл, где записаны ваши решения по
ролику, а всё остальное пересчитывается.
